# Published panel

`published_fig6b_panel.png` is Figure 6(b), extracted without changes from page 8
of [Liu et al. (2022), Towards Understanding Grokking](https://arxiv.org/abs/2205.10343).
The paper's authors are Ziming Liu, Ouail Kitouni, Niklas Nolte, Eric Michaud,
Max Tegmark, and Mike Williams.

It is included for comparison with our reproduction. The authors' saved data
are in `../../phase_diagram_plot/data_add_r.h5`.
